# Naadan Frenzy

A Kerala farm game for the browser, in the spirit of Farm Frenzy.

Grow grass from the well, raise hens and Kuttanad ducks, press coconut oil, fry banana chips, fend off jackals and monkeys, and send your auto-rickshaw to the market. Region 1 (Kuttanad backwaters) has 8 levels with gold, silver and bronze medals, plus upgrades.

**Play:** https://nmathewa.github.io/naadan_frenzy/

## Playing together
- **Kuttan:** a computer farm helper who works the same farm with you (Relaxed, Helpful or Expert).
- **Co-op with a friend:** one phone hosts and shows a 4-letter room code, the other joins with it. Both of you tap on the same farm. This uses a peer-to-peer connection (PeerJS), so it needs the public web version.

## About the code
Everything is in `index.html`: the art is drawn on a canvas and the music and sound effects are synthesised with Web Audio, so there are no image or audio files. Progress is saved in the browser.
